ABOUT THE PROJECT

A technology-assisted
farming concept.

AgriSmart is a college-project starter demonstrating how farm inputs can be collected through a website and used to produce a crop suggestion.

Project modules

  • Input formCollects nitrogen, phosphorus, potassium, temperature, humidity, soil pH and rainfall.
  • Recommendation logicShows a basic rule-based demonstration. It is not a trained machine-learning model yet.
  • Web interfaceFlask backend with responsive HTML and CSS frontend.
  • Future enhancementTrain and evaluate a model using a documented, trusted crop recommendation dataset; add validation and model metrics.
